# Language notes

- Blocks can use `:` + indentation or `{ ... }`
- `main()` is called automatically if present
- Arrays use `[1, 2, 3]`
- Objects use `Type { field: value }`
- Assignment supports `=`, `+=`, `-=`, `*=`, `/=`
- Builtins: `print`, `println`, `len`, `str`, `num`, `type`, `assert`, `clock`
- Modules: `std.io`, `std.math`, `std.fs`, `std.time`
